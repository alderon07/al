# Alias Lens 1.0.0-rc.2

This prerelease is for platform verification. Stable `v1.0.0` remains pending until the required native terminal, restart and package checks have dated results.

## Changes

The `rc.1` tag passed native shell checks and public installation, but publication stopped when the installation verifier could not remove Go's read-only disposable module cache. This candidate isolates writable module and build caches so verification completes and cleans up. The original tag remains unchanged.

- Guided catalog setup, reviewed native implementations, retained fallbacks, verified startup loading and offline rollback.
- Semantic catalog synchronization and restricted remote bootstrap with path-isolated Git operations.
- Corrected the public Go module and import paths so the documented Go installation route works.
- Closed the reported native declaration, tracked-source identity and managed Git isolation gaps.
- Reduced repeated import hashing, installed-state decoding allocations, search allocations and large-catalog Zsh handoff parsing.
- Required Linux and macOS Bash/Zsh workflow checks and exact-tag Go installation before release publication.

## Install the candidate

```bash
go install github.com/alderon07/al/cmd/alias-lens@v1.0.0-rc.2
alias-lens setup
```

Go installation uses Go 1.24.2 or newer. The executable is `alias-lens`; setup defines the shell command `al`. Go-installed binaries report the selected module version through `alias-lens --version`; `go version -m` also verifies the module identity and version.

Alternatively, select the Linux or macOS archive for your architecture, verify its checksum and provenance, and follow the README installation instructions. WSL uses the Linux archive. Native Windows shells are unsupported.
