# Catalog semantic sync acceptance

Catalog synchronization enrollment is separate from legacy native repository configuration. Format 1 enrollment records one absolute repository, one safe relative catalog path, exact saved base catalog bytes, base SHA, reviewed HEAD and blob, remote ref, managed ownership flag and optional durable push intent. App configuration stays version 2. Native installed mode is determined per shell from installed format 1; catalog shells never automatically push or replace their native fallback files.

Explicit pull observes saved base, local declared catalog and enrolled repository bytes under one mutation session, performs semantic three-way merge, and previews catalog and enrollment/base writes together. It never approves code or activates a generation. Conflicts save bounded private base/local/remote bytes with structured field conflicts; live catalog and native files remain untouched. Cancellation before apply writes nothing. Automatic inspection never merges remote catalog into local catalog or changes approval/ownership/activation.

Push scans all decoded catalog entries, current outgoing enrolled bytes and outgoing history. It commits only the enrolled path using an isolated index and Git plumbing. Unrelated index entries and worktree paths must remain byte-identical. A source commit and destination ref form a durable private push intent before network action. Push is never forced. Uncertain results remain pending and reconcile against the exact advertised destination object before any later push.

Managed Git runs with a bounded context and output, a minimal captured environment, disabled hooks, credential helpers, system/global configuration, fsmonitor, filters, submodules and LFS. Read commands use object plumbing and do not check out files. Managed shallow repositories refuse ancestry-dependent synchronization if ancestry cannot be proven. Credentials are confined to configured HTTPS authority and never appear in arguments, persisted remotes, config or public errors.

Verification uses disposable homes and local synthetic Git repositories. It covers independent semantic edits, conflicting edits, stale preview, invalid enrollment, missing base, malicious hooks/filter/fsmonitor, unrelated staged and dirty paths, outgoing history secrets, uncertain push reconciliation, installed mixed shell modes, readonly automatic inspection and PTY command workflows. No fixture reads real aliases, history, tokens or repository configuration.

A semantic catalog replacement first saves its exact prior bytes to a private revision whose name records the observed source modification timestamp and SHA. The revision and replacement commit in one typed transaction. Local enrollment status observes enrolled file bytes without Git; HTTPS status reports the last API-observed remote hash. Automatic catalog push may proceed only when the API-proven remote still equals the saved base, all scans pass, and there is no unresolved push intent. It never replaces the live catalog or activates it.

Remote path commits use the proven remote base tree and parent. A restricted metadata fetch may bring that base into the object database after approval, without writing FETCH_HEAD, refs, index or worktree. Filtering must be advertised and requested, and downloaded metadata and packet evidence remain bounded. Unmanaged repositories keep their branch and index unchanged after push. Managed repositories advance only their enrolled branch with an exact compare-and-swap.

The staged index contains the entire pinned HEAD metadata. Every non-enrolled tracked path is marked skip-worktree, the enrolled catalog is not, and initial staged differences are empty. Controlled credential prompts accept Git's exact trailing-space form only for the configured HTTPS authority and synthetic test credentials. Either stdout or stderr exceeding its bound rejects the operation even if the child exits successfully.

Configured SSH transport uses the HTTPS API solely for immutable repository proof. Git receives no provider token on SSH. SSH invokes the trusted system binary with no user or global SSH configuration, strict known-host checking against a private copy of a reviewed regular owned known_hosts file, agent-only identities from a validated owned Unix socket, no proxy, forwarding, interactive prompts or host enrollment. Unknown host or missing safe agent refuses SSH with manual local-enrollment guidance. The API host's hostname maps to SSH port 22, and the repository path is exactly API-proven. Configured `auto` uses SSH only when these local prerequisites are available, otherwise controlled HTTPS.

Known-host bytes and logical leaf identity bind remote bootstrap preview freshness and the enrolled SSH transport record. Durable push retries retain that proof. Every retry verifies the named source object's sole parent equals the saved remote base, tree differences affect only the enrolled path, bytes match the pinned SHA, destination ref equals the enrolled ref, and decoded entries and complete outgoing enrolled history pass the secret scan. Missing source objects refuse recovery. The local branch CAS observation is `local_head`, distinct from source parent `expected_remote`. HTTPS records carry no unused SSH proof.

Stage integration tests exercise actual filtered Git packets and promotion through a private local transport bridge, ignored filters, stale revision/blob, existing destination, cancellation with descendant termination, inert hooks/filter/LFS/submodule declarations, and destination filesystem placement. Synthetic SSH tests exercise `RunTransport` with a real owned Unix socket and pinned known-host bytes while a fake Git child inspects only controlled options and token absence. No test contacts production providers or uses production credentials.

Stage cleanup remains idempotent across a crash after removing the stage tree. When the destination is absent, recovery resumes removal of only the recorded, identity-matching empty parents. Already removed parents are accepted. A parent replaced by another inode is preserved and recovery refuses to discard its intent until ownership is restored or reviewed.
