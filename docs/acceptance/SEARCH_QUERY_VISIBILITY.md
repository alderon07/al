# Search query visibility

- Short typed queries appear in the search field itself in the alias picker and keyboard guide.
- Filtering uses the same visible query, including when there are no matches.
- Long queries keep their most recent characters visible with an ellipsis and stay within the field at narrow and wide terminal widths.
- A PTY check confirms query text appears in the rendered field after typing.
- The focused search field has a visible label and accent border; the command mode field has a muted border.
