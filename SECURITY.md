# Security policy

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/alderon07/al/security/advisories/new). Include the affected version, operating system and shell, impact, reproduction steps, and any suggested fix. Do not put provider tokens, alias files, shell history, configuration, or conflict copies in the report. Replace private values with clear placeholders.

Please do not open a public issue for an unpatched vulnerability. The maintainer will acknowledge a report within seven days, confirm whether it is in scope, and coordinate a fix and disclosure date when needed.

Supported releases and the current development branch receive security fixes until a 1.0 support window is published.
